# Data & Code Availability Statement

> **Standard**: Nature Digital Medicine / Lancet Digital Health Requirements

---

## 1. Public Datasets Used

The public datasets analyzed during model development and validation are available from their respective repository owners:
- **EyePACS**: Available via Kaggle Diabetic Retinopathy Detection Competition.
- **APTOS 2019**: Available via Kaggle APTOS 2019 Blindness Detection Competition.
- **DDR**: Available via grand-challenge.org / dataset repository.
- **IDRiD**: Available via IEEE Dataport / IDRiD challenge.
- **Messidor-2**: Available via LaTIM research group.
- **DRIVE / STARE / CHASE_DB1 / HRF**: Publicly available retinal vessel benchmarks.
- **Fundus-AVSeg (2025)**: Available via open-access research repository.

## 2. Gated & Restricted Datasets

- **UK Biobank**: Retinal imaging and outcome-linked follow-up data (Application ID: Gated) require formal application and institutional data transfer agreement with the UK Biobank Board.

## 3. Code Availability

Training pipeline code, dataset loaders, preprocessing scripts, evaluation suites, and PCCP changelog generators are open and maintained within the `training/` and `research/` directories of this repository.
